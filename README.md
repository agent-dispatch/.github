# AgentDispatch GitHub Profile

This repository is intended to be published as `agent-dispatch/.github`.

GitHub renders `profile/README.md` on the AgentDispatch organization page. This repo also provides organization-wide community health defaults:

- `CONTRIBUTING.md`
- `CODE_OF_CONDUCT.md`
- `SECURITY.md`
- `PULL_REQUEST_TEMPLATE.md`
- `.github/ISSUE_TEMPLATE/*`
- brand assets under `profile/assets/`
